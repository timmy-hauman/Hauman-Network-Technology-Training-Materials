單元 13:用戶端(Ivanti Secure Access Client)

講師導言

VPN 連線不是瀏覽器自己在跑,而是電腦上的「用戶端」軟體負責建立隧道。Ivanti 的用戶端叫 Ivanti Secure Access Client(簡稱 ISAC)。 這一章要回答四個問題:用戶端是怎麼被啟動的?裝給很多人要用哪種方式?怎麼設定連線,甚至讓使用者關不掉?連不上的時候,錯誤代碼怎麼讀? 最後有一個「連線問題診斷精靈」,讓你練習從症狀推回原因。

Goals 本章學習目標

  • 說出「瀏覽器登入 → PSAL 啟動 → ISAC 建立隧道」的流程
  • 比較四種部署方式:Web install、Preconfigured installer、Default installer、Installer Service
  • 在 Connection Set 設定 Always-on、VPN only access 與 Lock-down,並知道支援的平台
  • 看懂常見錯誤代碼(1111、1114、1107 / 1732 / 1701、1122、1214、1212、3007)的意思與處理方向
  • 知道怎麼收集用戶端日誌,交給管理員或原廠分析

本章銜接第 9 章的 VPN Tunneling(ESP、UDP 4500、SSL fallback、Route Monitor)與第 12 章的 Host Checker。

一、用戶端怎麼被啟動:從瀏覽器到隧道

用通勤接駁車來想

  • 瀏覽器登入像到櫃台買票、驗證身分。
  • PSAL像叫司機發車的對講機:由瀏覽器通知電腦「請把用戶端叫起來」。
  • Ivanti Secure Access Client是那台接駁車,載著你的流量走專用車道,也就是 VPN 隧道。

Ivanti Secure Access Client(ISAC)是安裝在使用者電腦上的 VPN 用戶端,舊名叫 Junos Pulse、Pulse Secure Client。 PSAL(Pulse Secure Application Launcher)則是「由瀏覽器啟動用戶端的元件」,取代了早年的 Java applet 和 ActiveX 啟動元件。 使用者登入網頁之後,由 PSAL 叫起 ISAC,ISAC 再和 ICS 建立隧道。 這是 Web install 的流程;用 Preconfigured installer 裝好,或由 Connection Set 設定後,也可以直接從用戶端連線。

三、安裝與部署:四種方式怎麼選

十個人和一千個人的做法不一樣。選擇的關鍵是:誰來裝?要不要預先帶入連線設定?使用者有沒有本機管理員權限?

方式說明適合

Always-on 與 Lock-down 的範圍

  • 支援 Windows 與 macOS,不支援 Linux。
  • 用戶端第一次從某台 ICS 取得設定後,會綁定那台伺服器,之後只有它能更新設定。
  • Lock-down 會在 VPN 建立之前封鎖其他網路流量,所以連線網址、DNS、憑證都要先確認沒問題,再大量啟用(這是教學建議)。

六、常見錯誤代碼與收集日誌

連不上時,用戶端通常會顯示一個四位數的錯誤代碼。先看代碼,可以少走很多彎路。

代碼意義處理方向
1111主機名稱無法解析檢查 DNS,或暫時改用 IP 連線
1114驗證失敗密碼變更後要清除用戶端存的舊帳密
1107、1732、1701伺服器憑證驗證失敗 / 名稱不符 / 超出有效期檢查憑證 SAN 與用戶端時鐘
1122端點沒通過合規檢查檢查 Host Checker 結果
1214ESP 連線失敗,而且管理員關閉了 SSL fallback檢查 UDP 4500 是否被擋
1212路由表衝突,Route Monitor 觸發斷線找出改路由的程式
3007連線逾時檢查網路與防火牆

代碼表出自 2023 年版官方錯誤訊息指南,新版可能略有增減。

收集用戶端日誌

  1. 1使用者自己匯出:用戶端選單 File > Logs > Save As,會產生 LogsAndDiagnostics.zip。
  2. 2管理員設定自動上傳:在角色的 Session Options 開啟日誌上傳。
  3. 3管理員查看:System > Log/Monitoring > Client Logs > Uploaded Logs。

八、常見踩坑與版本差異

密碼改了,用戶端還記著舊的

AD 密碼變更後,用戶端存的舊帳密會一直送出去,出現 1114 驗證失敗。處理方向是先清除用戶端存的舊帳密,而不是一直重試。

憑證名稱不符、電腦時間不對

1107、1732、1701 這一組都和伺服器憑證有關。第 4 章要求正式憑證的 SAN 包含 vpn.example.com;另外用戶端電腦的時鐘如果差太多,憑證會被當成「還沒生效」或「已過期」。

UDP 4500 被擋,又關了 SSL fallback

外部防火牆要放行 TCP 443 與 UDP 4500。如果 ESP 走不通,而管理員又關閉了 SSL fallback,使用者就會看到 1214。想讓 ESP 走不通時仍能連線,就保留 SSL fallback;關閉它的話,UDP 4500 一被擋就連不上。

其他程式改路由,隧道自己斷了

第 9 章把 Route Monitor 設成 Yes,是為了防止程式偷改路由、繞過隧道。所以另一套 VPN 或網路工具改了路由表,用戶端就會斷線並顯示 1212。處理方向是找出改路由的程式。

版本差異

  • 用戶端名稱:Junos Pulse、Pulse Secure Client 已更名為 Ivanti Secure Access Client(22.2R1,2022-07)。
  • 桌面版 25.1.0 已於 2026-10-13 發行,平台清單以實機為準;22.x 系列最新為 22.8R7。
  • 錯誤代碼表出自 2023 年版官方錯誤訊息指南,新版可能略有增減。
  • Always-on 與 Lock-down 支援 Windows 與 macOS,不支援 Linux。
