Ivanti Connect Secure SSL VPN 實戰課程

單元 16:備份、升級與遷移

講師導言

升級是 VPN 維運裡風險最高的動作之一,而且 25.x 之後不支援降版:升上去發現不對,通常回不去了。所以這一章的順序是:先學會備份,再學升級,最後學「什麼情況根本不能升、只能遷移」。 最後的「升級路徑規劃器」會依你目前的版本、硬體和是否叢集,告訴你該就地升級、做設定遷移,還是得先換硬體。

Goals 本章學習目標

  • 說出 system.cfg 與 user.cfg 各包含什麼,以及為什麼完整備份兩個都要匯出
  • 匯出加密碼的備份檔,並分辨匯入 system.cfg 的三個選項
  • 依序完成同一台設備的升級,知道 Deletes 為什麼不能勾
  • 分辨「就地升級」、「設定遷移」、「要換硬體」三種情況
  • 辨認叢集 22.8 到 25.x 不能直升、25.x 不支援降版等關鍵警告

叢集的升級與重建會用到第 14 章的建立叢集步驟;各機型與版本的支援期限見第 1 章。

一、備份:兩個檔案各裝什麼

用搬家來想

  • system.cfg 像「房子本身」:水電、網路孔、門牌、管委會登記(網路、憑證、叢集、授權)。
  • user.cfg 像「住戶與規矩」:誰住哪一間、誰能進哪些房間(登入政策、Realm、角色、資源政策、本機帳號)。
  • 搬家只帶住戶不帶房子的資料,或只帶房子不帶住戶,都不算搬完。完整備份兩個檔都要匯出。
檔案內容位置
system.cfg網路設定、設備憑證、叢集設定、授權、SNMP 等Maintenance > Import/Export > Import/Export Configuration
user.cfgAuthentication、Administrators、Users 選單下的所有設定:登入政策、Realm、角色、資源政策、本機帳號Maintenance > Import/Export > Import/Export Users

選單位置改了

舊版設定手冊寫的是 System > Configuration > Import/Export。現行版本已經改到 Maintenance > Import/Export,照舊手冊找不到時,到 Maintenance 底下找。

  1. 1匯出時設定密碼(輸入兩次),保護備份檔。密碼要和備份檔分開保管。
  2. 2按匯出,把檔案存到 ICS 以外的安全位置。
  3. 3匯入時先選要匯入的檔案。
  4. 4匯入 system.cfg 有三個選項,三選一:
    • Import everything (except Device Certificate(s)):除了設備憑證,其他全部匯入。
    • Import everything but the IP address:保留目前的網路位址,其他全部匯入。
    • Import everything except network settings and licenses:不匯入網路設定與授權。來自叢集節點或備援機時用。
  5. 5按匯入。user.cfg 在另一頁(Maintenance > Import/Export > Import/Export Users),同樣要匯出一份。

其他備份與搬移設定的方式

方式做什麼注意
XML 匯出匯入只處理選取的設定,適合批次修改來源與目標必須是相同軟體版本
自動備份Maintenance > Archiving > Archiving Servers,可排程送到 SCP、FTP、AWS S3、Azure Storage本機備份(Local Backups)只保留最近 5 份
Push ConfigMaintenance > Push Config,把設定推到其他不在同一叢集的設備網路、授權、叢集、憑證、SNMP、Syslog 不會被推送

三、同一台設備的升級

升級前的三件事

  • 先備份 system.cfg 與 user.cfg,並記下叢集名稱、密碼與各節點的內部網路設定。
  • 依 Ivanti KB44877 完成升級前的必要步驟。這篇需要登入才能閱讀,內容以官方文件為準,本教材沒有核對。
  • AD 驗證伺服器若還是 Legacy Mode,先改成 Standard Mode。

兩個一定要記住的操作限制

  • 不要從 External port 進行升級。
  • 叢集只在一台安裝,重開機後會自動推送給其他節點。不要逐台安裝。

四、回復:Rollback

升級之後如果要退回,入口在 Maintenance > System > Platform 的 Rollback 按鈕。

  1. 1Rollback 按鈕只有在設備升級過之後才會出現。沒升級過的設備,這一頁看不到它。

能不能回復,看版本

  • 【25.x】25.1.3.0 的 Release Notes 寫明不再支援降版(Downgrade)。升級前一定要先備份,別假設出事了可以退回去。
  • 【22.x】22.8R2 起是 Secure Boot 版本,升上去之後不能 rollback 到非 Secure Boot 的版本。

五、升級路徑與遷移:哪些能升、哪些只能搬

升級像翻修,遷移像搬家

  • 就地升級:人還住在原來的房子裡,把裝潢換新。房子的結構要撐得住才行。
  • 設定遷移:在新房子裡把家具和規矩全部重新擺好。舊房子不動,新房子先佈置好才切換。
  • 要換硬體:舊房子根本撐不住新裝潢,只能先買新房子,再搬家。

升級到 25.1 各情境的做法如下(目標版本以各列為準):

情境做法
22.8R2.x → 25.1(就地升級)25.1.0.0 只能從 22.8R2 升;25.1.1.0 可從 22.8R2.1 / .2 / .3 升。22.7 要就地升級,得先升到 22.8R2
22.7 / 22.8 → 25.1.3(設定遷移)25.1.3.0 的遷移表列出可從 22.7R2.14、22.8R2.4 等版本匯出設定,再匯入新機
就地升級到 25.1.3只支援 ISA6500 / 8500 上的 25.1.2.x
叢集 22.8 → 25.x不支援直接升級。要拆開叢集、個別升級,再重建叢集
ISA6000 / 8000 → 25.1.2 以上不能升。這兩款最多到 25.1.1.x,要換 ISA6500 / 8500 再遷移設定
舊虛擬版 → 25.1.3不能直升,要部署新的虛擬版再遷移
9.1Rx / PSA → ISA遷移,不是升級。見下方步驟

從 9.1Rx / PSA 遷移到 ISA 的八個步驟

  1. 舊機先升到 9.1R14.6 以上,AD 驗證伺服器改成 Standard Mode。
  2. 新機先上線,安裝新授權(PSA 授權不能沿用)。
  3. 舊機匯出 system.cfg、user.cfg 與 XML(System Settings 全選)。
  4. 記下舊機的 IP、叢集、Virtual Ports、VLAN、Hosts、路由、DNS、SNMP、Syslog 設定。
  5. 新機先設定網路介面、Management port、VLAN、靜態路由。
  6. 新機匯入 system.cfg,選 Import Everything except network settings, cluster settings, and licenses,再匯入 user.cfg。
  7. 叢集環境:先在第一台建立新叢集,再加入第二台(第 14 章)。
  8. 驗證叢集狀態與登入,手動複核網路設定、路由與 Hosts。

匯入選項的名稱,兩份文件寫法不同

第 6 步的選項名稱,遷移指南寫成 Import Everything except network settings, cluster settings, and licenses;Admin Guide 則寫成 Import everything except network settings and licenses。實機上到底叫什麼,以實機為準。

匯入時,已棄用功能的設定(例如 SiteMinder、NIS 驗證伺服器)與引用它們的政策,會被自動刪除。遷移完成後要檢查有沒有政策因此消失。

七、常見踩坑與版本差異

安裝套件時勾了 Deletes

Deletes 勾下去會清空所有設定。升級時它必須保持未勾。

叢集逐台安裝,或從 External port 升級

叢集只在一台安裝,重開機後會自動推送給其他節點。升級也不要從 External port 進行,請用 Internal 或 Management port 連到管理介面。

只備份了一個檔

只有 system.cfg,還原後沒有 Realm、角色與政策;只有 user.cfg,還原後沒有網路與憑證。兩個檔都要匯出,並記下叢集名稱、密碼與各節點的內部網路設定。

把 9.1Rx 或 PSA 的升級當成「按 Install」

9.1Rx / PSA 到 ISA 是遷移,不是升級,而且 PSA 的授權不能用在 ISA 上,換機要買新授權。AD 驗證伺服器還在 Legacy Mode 的話,升級或遷移前也必須先轉成 Standard Mode。

版本差異與待確認

  • 25.x 不支援降版;22.8R2 起的 Secure Boot 版本不能 rollback 到非 Secure Boot 版本(第四節)。
  • 遷移匯入 system.cfg 的選項名稱,兩份官方文件寫法不同,以實機為準(第五節)。
  • 升級前的必要步驟寫在 KB44877,該文章需要登入才能閱讀,動手前請自行查閱。
