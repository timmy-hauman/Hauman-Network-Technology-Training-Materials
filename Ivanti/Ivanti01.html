Ivanti Connect Secure SSL VPN 實戰課程

單元 1:產品沿革與現況

講師導言

打開手邊的舊教材,你會看到 IVE、Juniper SA、Pulse Secure、Network Connect、WSAM 這些名字。它們和今天的 Ivanti Connect Secure(ICS)25.1 是同一條產品線,只是經過幾次併購與改名,有的換了名字、有的被取代、有的已經移除。 這一章先把名字的來龍去脈講清楚,再看每個版本與每款硬體的支援期限,最後用一個小工具檢查「我的設備還在不在支援範圍內」。

Goals 本章學習目標

  • 說出產品名稱從 IVE、Juniper SA、Pulse Secure 到 Ivanti 的演進順序
  • 拿舊教材的名詞,查表找到現行介面上對應的名稱
  • 看懂版本生命週期表,說明 End of Engineering、End of Support 與 N-2 政策
  • 分辨 PSA、ISA6000 / 8000、ISA6500 / 8500 與各種虛擬版的支援狀態
  • 說出 Gateway(並行)與 Named User 兩種授權模式的差別,以及授權斷線時的寬限期

本章的日期與狀態,一律以教材的查證日 2026-10-31 為準。

三個要看懂的詞

End of Engineering

這個日期之後,只剩「盡力而為」的修補,不再期待有完整的新修正。

End of Support

終止支援日。過了這一天,這個版本線就不在官方支援範圍內。

N-2 政策

Ivanti 支援「目前的 minor 版本」加上前兩個 minor,每個 minor 約 9 個月。

22.7 與 22.8 的期限

Ivanti 把 22.8 定位為「22.7 到 25.1 之間的過渡橋梁」。22.7 與 22.8 都必須在 2027-01-31 前遷到 25.1。

教學建議

本課程以 25.1.x 為主。22.x 只在講升級、遷移時提到;9.1Rx 與更舊的版本當歷史背景就好。

PSA 的授權不能用在 ISA 上

從 PSA 換成 ISA,要買新授權,舊授權不能搬過去。做預算時別漏掉。

五、授權模式與產品定位

用停車場來想

  • Gateway(並行)模式像算「同一時間停了幾輛車」,看的是同時連線的裝置數。
  • Named User 模式像算「發了幾張月票」,看的是有多少位使用者,一張票可以配給同一個人的幾台裝置。
模式計算方式重點
Gateway(並行)模式依同時連線的裝置數需要平台 / core 授權,由 License Server 租用
Named User 模式依使用者人數即 Unified Access License(UAL)。每位使用者佔一個授權、最多 5 台裝置,綁定 Ivanti Neurons for Secure Access(nSA),同時涵蓋 VPN 與 ZTA
  • 兩種模式可以切換。
  • ISA-V 不能直接安裝授權,只能當 license client 向 License Server 租用;所有 ISA-V 授權都是訂閱制。

失去授權伺服器連線時的寬限期

情境寬限期
ISA-V 訂閱授權失去與 Ivanti 雲端授權服務(PCLS)的連線24 天
失去與 License Server 的連線10 天
叢集節點故障10 天
ICS 訂閱授權(Secure Access Platform)31 天

25.x 是否只賣訂閱、不再賣永久授權,公開文件查不到,請向經銷商確認。

產品定位

Ivanti 把 Connect Secure 定位為「通往零信任(Zero Trust)的 VPN 閘道」。它和另一個產品 Ivanti Neurons for Zero Trust Access(ZTA)共用同一個用戶端(ISAC)與管理平台(nSA)。 傳統 SSL VPN 並沒有被取消,但必須跟著平台升到 25.x。

七、常見踩坑與版本差異

照舊教材找選單,找不到就以為自己設錯

舊教材裡的 Network Connect、WSAM、Secure Meeting 這些功能,在新版要嘛換了名字、要嘛已經移除。找不到不是你的問題,先回第二節查表。

把 22.8 當成長期版本

22.8 是「22.7 到 25.1 之間的過渡橋梁」,End of Support 是 2027-01-31。現在才從 22.x 開始新專案,等於一開始就背著遷移的工作。

只看版本、不看硬體

版本還在支援期,不代表那台設備也在支援期。ISA6000 / 8000 最多只能跑到 25.1.1.x;舊虛擬版不能直接升到 25.1.3。升級前先把版本和硬體一起對照。

版本差異

  • 25.1 是新平台:Oracle Linux 9、SELinux enforcing(Linux 的強制存取控制機制)、Secure Boot / TPM、內建 WAF(網頁應用程式防火牆);22.x 則是 2021-10 出貨的 Modern stack,取代 9.1Rx 舊架構。
  • 查證日當下,有 release notes 可查的最新版是 25.1.3.1。版本矩陣另外列出 25.1.4.x(2026-10-15),但還查不到它的 release notes,它的支援日期請以實機或原廠公告為準。
  • 舊的 Anonymous、NIS、SiteMinder 驗證伺服器,以及 AD 驗證伺服器的 Legacy Mode,遷移到 25.1 前都要先處理。
