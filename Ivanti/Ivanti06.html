單元 6:使用者角色(User Role)

講師導言

帳密驗證過了,使用者能做什麼?答案寫在角色(User Role)裡。角色就是一組權限:啟用哪些存取功能、Session 可以維持多久、在什麼條件下才生效。 這一章要建立角色、勾選存取功能、設定 Session 時間,並認識幾個舊教材常見、新版卻已經找不到的功能(例如 Network Connect 與 Telnet/SSH)。 最後的模擬器會讓你親眼看到,為什麼有時候「明明設了 30 分鐘,卻 10 分鐘就被登出」。

Goals 本章學習目標

  • 說出一個角色最重要的三件事:存取功能、Session Options、Restrictions
  • 建立角色並勾選對應的存取功能
  • 認出舊教材裡已移除或改名的功能,知道新版該用什麼取代
  • 設定 Idle Timeout 與 Max. Session Length,並說明「Overview 沒勾 Session Options」的後果
  • 用 Restrictions 依裝置狀態決定角色要不要生效
  • 分辨預設的管理角色與委派角色

本章對應第 2 章「登入評估流程」的第 7 項(檢查 Restrictions)與第 9 項(確認角色有啟用對應的存取功能)。

一、角色最重要的三件事

用一張門禁卡來想

  • 存取功能像卡片能開哪幾種門:辦公區的門、機房的門、停車場的門。
  • Session Options像卡片的有效時間:閒置多久要重新刷卡、一次最多待多久。
  • Restrictions像發卡條件:只有帶著公司配發的工作證,才會發這張卡給你。

User Role(使用者角色)就是一組權限。選單位置:Users > User Roles。一個角色最重要的三件事(另外還有 UI Options 等設定):

角色勾了功能,不等於什麼都能連

登入評估流程裡,第 9 項先確認角色有啟用對應的存取功能,第 10 項才由 Resource Profile / Policy 決定具體能連哪些資源。所以「角色」管的是大門有沒有開,「資源」管的是能走進哪些房間(第 8 章)。

名詞小卡

存取功能

在 General > Overview 勾選,決定這個角色能用 Web、檔案分享、VPN 隧道等哪幾種連線方式。

Session

使用者登入後到登出(或被系統結束)之間的這段連線期間。

Restrictions

角色的生效條件。條件沒通過,使用者只是拿不到這個角色,不一定登入失敗。

UI Options

使用者介面相關的選項。和 Session Options 一樣,要在 Overview 勾選後才能自訂。

示意畫面:欄位名稱依 Ivanti 官方文件,版面、按鈕位置、單位與預設選取項目以實機為準。
  1. 1Idle Timeout:使用者閒置超過這段時間,Session 就結束。
  2. 2Max. Session Length:Session 最長可以維持多久,時間到就結束。
  3. 3Reminder Time:和逾時提醒有關的設定。
  4. 4Enable Session Extension、Enable session timeout warning:是否允許延長 Session,以及逾時前是否跳出警告。
  5. 5Roaming session:使用者的連線環境改變(例如筆電換了網路)時,Session 要不要繼續有效。選項有 Enabled、Limit to subnet、Disabled,依公司政策選擇。
  6. 6按 Save Changes。

四、Restrictions:依條件決定角色要不要生效

位置:Users > User Roles > (角色) > General > Restrictions。可以依來源 IP、瀏覽器、用戶端憑證、Host Checker 結果,決定這個角色是否生效(舊版設定手冊的觀念到現在都不變)。

用途舉例:同一個員工,從公司配發、通過 Host Checker 的筆電登入時拿到「完整 VPN」角色;從個人電腦登入時只拿到「網頁存取」角色。

登入的裝置Host Checker 結果拿到的角色
公司配發的筆電通過完整 VPN 角色
個人電腦沒通過只有網頁存取角色

Restrictions 沒通過 ≠ 一定登入失敗

登入評估流程第 7 項:檢查每個可用角色的 Restrictions,只留下符合條件的角色,被過濾掉的角色不生效。只要使用者還有其他符合條件的角色,就仍能登入,只是少了被過濾掉的那個角色。如果希望「條件沒通過就整個登入失敗」,條件要設在 Realm 的 Authentication Policy(第 7 章會比較兩者)。

五、VPN Tunneling 選項與管理員角色

VPN Tunneling 的角色選項

分流、路由優先權等設定放在角色層級,第 9 章一起講。

管理員角色與委派

位置:Administrators > Admin Roles。管理員用的角色和使用者角色是分開的。

  • 預設角色 Administrators 與 Read-Only Administrators 不能刪除或複製,只能改 General 分頁。
  • 可以新建委派角色(New Role 或 Duplicate),依分頁(System、Users、Administrators、Resource Policies、Resource Profiles)給讀或寫的權限。
  • 委派管理員不能自行提升權限。Import/Export、Push Config、本機備份只保留給預設角色。
  • 管理員帳號建在對應的 Auth Server,不是建在角色裡。

六、動手玩:Session 逾時時間軸

選擇逾時設定與使用情境,看看 Session 會在第幾分鐘結束,是因為閒置,還是達到最長時間。取消勾選「Overview 有勾選 Session Options」,可以看到套用預設值的後果。(情境的操作時間為教學範例值。)

角色設定

使用情境

情境說明:持續使用不停 = 一直有操作;中午離開 40 分鐘 = 登入後第 20 分鐘離開、第 60 分鐘回來;每 20 分鐘操作一次 = 第 0、20、40…分鐘各操作一次。

下限:Idle Timeout 5 分鐘、Max. Session Length 6 分鐘。預設:10 分鐘 / 60 分鐘。

Session 時間軸

使用者在操作 一次操作 Session 結束後才想操作 閒置計時中 Session 結束

七、常見踩坑與版本差異

Overview 沒勾 Session Options,改的設定都沒生效

Session Options 頁的數字改得再仔細,只要 Overview 沒有勾選 Session Options,角色就套用預設值(Idle Timeout 10 分鐘、Max. Session Length 60 分鐘)。使用者抱怨「怎麼 10 分鐘就被登出」時,先回 Overview 看這個勾選框。

沿用舊教材的 Telnet/SSH 或 Network Connect 範例

新版的存取功能清單裡已經沒有這兩項。Network Connect 改名為 VPN Tunneling;要在瀏覽器連 SSH,改用 HTML5 Access(Telnet 本來就是明文,更不該再用)。

勾了存取功能,卻沒設資源

角色只負責「這個功能的門有沒有開」。使用者登入後看不到書籤、打不開網站,多半是 Resource Profile / Policy 沒有指派給這個角色(第 8 章)。

用 Restrictions 想擋整群人

Restrictions 沒通過,只是拿不到這個角色,使用者可能還拿得到別的角色。要讓整個 Realm 都進不來,條件該放在 Realm 的 Authentication Policy(第 7 章)。

版本差異

  • Network Connect 從 9.1R2 起移除,改名為 VPN Tunneling。
  • Telnet/SSH 在 21.x 標示 deprecated,新版以 HTML5 Access 取代。
  • Meetings、Email Client 已移除;新版功能清單只列 Files (Windows),不再列 Files (UNIX/NFS)。
  • 新增的存取功能:HTML5 Access、Secure Mail、Enterprise Onboarding。
