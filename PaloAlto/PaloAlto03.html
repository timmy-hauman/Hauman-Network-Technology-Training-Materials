Palo Alto Networks NGFW 實戰課程

基礎篇 - 單元 3：授權、更新與最佳實務範本

講師導言

防火牆接上管理網路之後，下一步不是急著寫規則，而是先讓它「有資格運作」：啟用授權、把軟體與內容更新到位，再了解原廠公開的最佳實務範本。 這三件事做不好，後面的威脅防護、URL 過濾、DNS 防護都可能只是看起來有開、實際沒生效。 這一章也是教材跟現行原廠文件落差最大的地方：訂閱服務多了更高一級的進階版，組合也不同了，上課時請把「教材寫法」與「現行寫法」對照著看。

Goals 本章學習目標

  • 依序說出啟用一台新防火牆的步驟，並分辨硬體機型與 VM-Series 的差別
  • 說明 Device > Licenses 的三種授權啟用方式，以及什麼情況該用哪一種
  • 認得現行訂閱服務的名稱（Advanced 系列），並指出彼此的相依關係
  • 完成 PAN-OS 軟體更新的基本流程，並說明升級路徑的注意事項
  • 區分軟體更新與內容更新（Dynamic Updates），知道新應用程式簽章進來前要先預覽影響（操作細節見第 12 章）
  • 說明 IronSkillet 是什麼、載入前要注意哪些事，以及它對現行版本的適用範圍

Flow 一、啟用防火牆與授權

新設備到貨後，先到原廠的 Customer Support Portal 註冊，再回到防火牆啟用授權。 硬體機型用序號，VM-Series 用寄來的授權碼（auth code）與訂單編號（現行授權方案的實際流程以入口網站為準）。 啟用動作在 Device > Licenses 進行。

步驟 硬體防火牆 VM 防火牆（VM-Series）
1. 向原廠支援註冊使用 Dashboard 上顯示的序號使用 email 收到的授權碼與購買／訂單編號
2. 啟用授權在 Device > Licenses 取回授權金鑰，或用授權碼啟用
3. 確認更新與 DNS 伺服器在 Device > Setup > Services 設定正確的更新伺服器與 DNS 伺服器（第 2 章已設定）
4. 管理內容更新取得最新的應用程式與威脅、防毒、WildFire 等內容更新（教材另列 URL 過濾資料庫；現行 URL 分類主要由 Advanced URL Filtering 在雲端查詢，是否仍需下載資料庫以實機為準）
5. 安裝軟體更新確認 OS 版本，安裝建議的版本

Device > Licenses 的三種啟用方式

選項（UI 原文）適用情境
Retrieve license keys from license server授權已經在 Customer Support Portal 啟用過，防火牆從授權伺服器把金鑰取回來
Activate feature using authorization code授權還沒在入口網站啟用，直接在防火牆上輸入授權碼
Manually upload license key防火牆連不到入口網站（例如離線環境）：先在有網路的電腦下載金鑰檔，再上傳到防火牆

🎫 生活化比喻：買了票還要劃位

買訂閱服務就像買了音樂節的票：票號（授權碼）要先到售票系統登記，現場閘門（防火牆）還得能連回售票系統確認，才放你進去。連不上系統的場地，就只能拿事先印好的紙本票券（手動上傳金鑰檔）。

踩坑：授權啟用失敗，先查連線，不要急著重打授權碼

  • 透過授權伺服器取回金鑰或用授權碼啟用，都需要防火牆能連到授權伺服器；DNS 伺服器設錯或沒設，是最常見的原因（第 2 章的 Device > Setup > Services）。
  • 沒有有效的 Support 授權，就無法更新 PAN-OS 軟體。
  • 啟用 WildFire、Advanced URL Filtering、DNS Security 之後，需要 Commit 讓防火牆開始處理相關流量；若沒有待提交的變更，做法是用 CLI 的 commit force（Commit 概念見第 4 章）。

版本差異

教材（PAN-OS 9 / 10 時代）的內文只寫到「在 Device > Licenses 取回金鑰或用授權碼啟用」，講師備註則提到要先在 Device > Support 啟用 Support 授權。現行文件另列了 Manually upload license key（防火牆連不到授權伺服器時使用），並要求先安裝 NGFW 的裝置憑證（device certificate），才能使用原廠雲端服務。管理介面與初始設定請回頭參考第 2 章。

Concept 二、訂閱服務：名稱與相依關係

授權分成兩類：一類是設備本身（Support、VM 容量等），另一類是訂閱服務，由原廠雲端持續提供簽章與分析。 原廠現在把其中多項歸類為「雲端交付安全服務（Cloud-Delivered Security Services）」。以下是現行文件列出的主要安全類訂閱：左欄是基礎版，中欄是更高一級的進階版。進階版是另外訂閱的服務，不是基礎版改名：

基礎版 進階版（另行訂閱） 差異與相依
Threat PreventionAdvanced Threat Prevention基礎版含防毒、反間諜、弱點防護等；進階版加上雲端的深度學習引擎，偵測規避型 C2 威脅，並包含基礎版全部功能（第 13 章）
DNS SecurityAdvanced DNS SecurityDNS Security 要先有 Threat Prevention；進階版加上雲端引擎即時偵測遭劫持與設定錯誤的網域，並包含 DNS Security 全部功能
URL FilteringAdvanced URL FilteringURL Filtering 已不單獨販售，功能都包含在進階版；進階版以機器學習做即時網頁檢查
WildFireAdvanced WildFireWildFire 分三級：基本 WildFire 內含在防火牆中，簽章要透過防毒或 Threat Prevention 更新取得；WildFire 訂閱加快簽章更新並支援更多檔案類型；Advanced WildFire 是另外加購的更高一級訂閱，不是 WildFire 改名，並包含 WildFire 訂閱的全部功能，再加上雲端執行期記憶體分析，偵測規避型惡意程式

其他常見授權

GlobalProtect Gateway

基本部署不需授權；進階功能（如 HIP 檢查、行動 App、外部 Gateway 的 IPv6、無用戶端 VPN）才需要，依 Gateway 計；內部 Gateway 的 IPv6 自 App 4.1.3 起不需授權，細節以實際授權為準（第 16 章）。

Virtual Systems

永久授權，用於多個虛擬系統。部分機型必須有，其餘機型要超過預設數量才需要。

Strata Logging Service

雲端集中儲存與彙整日誌。

其他

原廠文件另列 Enterprise DLP、SaaS Security Inline、Device Security、SD-WAN、AutoFocus、Strata Cloud Manager 等，本課程不展開。

版本差異

  • 教材投影片（約 2017～2020 年）談到的授權，是以當時的 Threat Prevention、WildFire、URL Filtering（PAN-DB）為主。現行原廠文件已經多了 Advanced Threat Prevention、Advanced WildFire、Advanced URL Filtering、Advanced DNS Security。
  • 「URL Filtering 不再單獨販售」是教材沒有的新事實；舊文件裡看到的 PAN-DB URL Filtering 訂閱，在新採購時要改看 Advanced URL Filtering。
  • 名稱會隨原廠產品策略調整（例如日誌服務現行文件名為 Strata Logging Service）。實際採購與續約內容，請以原廠或代理商報價單為準。

踩坑：只買了 DNS Security，沒有 Threat Prevention

DNS Security 要先購買並安裝 Threat Prevention 授權。盤點授權清單時，要看的是「相依關係有沒有齊」，不是單看有沒有那一項。另外，不論訂閱服務有沒有啟用，設定檔（Profile）有沒有套進安全政策規則才決定流量有沒有被檢查（第 9、13 章）。

Config 三、PAN-OS 軟體更新

軟體更新在 Device > Software。基本三步：Check Now 列出新版本 → 下載（從更新伺服器 Download，或從本機 Upload）→ Install。 安裝完需要重新開機才會切換到新版本。

Action 欄位意思
Validate該版本在原廠更新伺服器上，可以下載
Install該版本已在防火牆上，可以安裝（需要重新開機）
Reinstall曾經安裝過，可以再安裝一次

升級路徑要先看

  • PAN-OS 版本編號分大版本（feature release）與維護版本（maintenance release）；每個大版本會先有一個 base image（基底映像檔）。
  • 不要安裝非目標版本的 base image，也就是只有當某個大版本就是你的升級目標時，才安裝它的 base image。
  • 手動升級時，原廠建議從每個版本最新的維護版本開始往上走。
  • 升級 PAN-OS 前，先把內容更新（見下一節）更新好；每個 PAN-OS 版本都有最低支援的內容版本。

版本差異

早期的規則是「大版本不能跳著升，每個大版本都要裝過」；教材講師備註的例子是從 8.1 升到 9.1，要先安裝 9.0.0 再安裝 9.1.0。後來原廠提供 Skip Software Version 功能（從 PAN-OS 10.1 或更新的版本升級時可用）：例如從 11.0.x、11.1.x、11.2.x 可直接升到 12.1，已在 12.1 的可直接升到更後面的版本。但可略過的範圍因來源版本而異（例如 10.2.x 的直升目標是 11.2），動手前請依原廠升級路徑表確認，不要憑印象。

踩坑：升級路徑沒查就動手

  • 把中間版本的 base image 也安裝進去，或沒看來源版本能否直升，會讓升級卡關，甚至要回頭重做。
  • 沒有有效的 Support 授權就無法下載更新（見第一節）。
  • HA 成對設備可以用 Device > Software 的 Sync To Peer 把上傳的映像檔推給對端；實際的升級順序屬於第 17 章，集中管理多台設備的升級則在第 18 章（Panorama）。正式環境升級前，先匯出並備份設定（第 4 章）。

Config 四、內容更新：Dynamic Updates

軟體更新換的是「作業系統」，內容更新換的是簽章與資料庫，兩者獨立管理。 選單是 Device > Dynamic Updates：可以排程檢查新內容並自動下載，或下載並安裝；也可以手動下載、安裝，或還原（Revert）到先前版本。

內容類型 內容與授權需求
Applications and Threats應用程式（App-ID）與威脅簽章，需要 Threat Prevention 授權。對有授權的設備，它取代單純的 Applications 更新（第 12、13 章）
Antivirus防毒簽章，原廠約每 24 小時發布；沒有 WildFire 訂閱時，WildFire 簽章要至少延遲 24 小時才會經由防毒更新送達（此節奏來自較舊版本的說明，12.x 以實機為準）
WildFireWildFire 訂閱可即時（real-time）取得 WildFire 雲端產生的簽章，也可改用排程定期檢查，排程選項以實機為準。教材寫的是約每五分鐘發布一次、最快每分鐘檢查一次，現行版本多了即時取得的選項。
GlobalProtect Data File放廠商相關的 HIP 資料，需要 GlobalProtect Gateway 授權，而且要建立排程，GlobalProtect 才會正常運作
Device Dictionary供 Device Security（IoT）使用的裝置字典

新應用程式簽章進來前，先預覽對政策的影響

內容更新帶進新的 App-ID 時，原本被辨識成 web-browsing 之類的流量可能換了一條規則比對，所以安裝前要先預覽影響；操作細節見第 12 章。

版本差異

  • 早期教材（PAN-OS 8.0）寫 App-ID 是「每週更新（Weekly updates）」；較新的教材講師備註則寫新應用程式每月新增。較新版本（例如 PAN-OS 10.2 時期）的原廠說明是：新的 App-ID 在每個月第三個星期二發布，已有應用程式的修改則更頻繁；Applications and Threats 更新「有時一週數次」。實際節奏可能再變，排程前請以實機與當時的原廠說明為準。
  • 教材投影片只列出排程與手動下載、安裝（講師備註提到可先下載到另一台電腦再上傳）；現行 UI 另有 Threshold（Antivirus、Applications and Threats 的最短等待時間）與 Install From File（離線環境從支援網站下載檔案、上傳後再用它安裝）。
  • 教材未列的類型，如 Device Dictionary、GlobalProtect 相關資料檔，現行文件都有說明（見上表）。

Best Practice 五、最佳實務範本：IronSkillet

IronSkillet 是 Palo Alto Networks 在 GitHub 上公開的專案（PaloAltoNetworks/iron-skillet），目的是提供第一天（Day 1）的最佳實務設定範本，可載入到 NGFW 或 Panorama。 教材的說明是：它落實入站、出站與內部流量防護的方法論、載入設定與自訂報表，並縮短部署時間、減少錯誤。 教材也提到，Day 1 設定在註冊新防火牆時，也能從 Support Portal 取得（現行流程以入口網站為準）。

🍳 生活化比喻：新房子的標準裝潢包

IronSkillet 像建商附的「標準裝潢包」：水電、消防、基本安全設備先做到位，之後你再依需要擺家具（介面、區域、NAT、安全規則）。它不替你決定房子怎麼隔間。

範本涵蓋什麼，不涵蓋什麼

範本重點

  • 動態更新（dynamic updates）、安全設定檔（security profiles）、規則（rules）、日誌（logging）等，讓各部署一致
  • 提供多種「播放清單（playlist）」，例如 full config、security profiles only、alert only 等，可選擇只載入一部分

仍需自己設定

  • 介面、區域、路由（第 5、6 章）
  • 允許清單式的安全規則、User-ID、解密政策（第 8、9、14、15 章）
  • 原廠最佳實務中需要手動設定的項目

怎麼載入

載入方式說明
Skillet Player（panHandler）圖形化應用程式，用來安裝並執行（play）IronSkillet 與其他 skillet
SLI命令列工具，例如 sli load 載入工作目錄中的 skillet
手動：完整 XML透過 Device > Setup > Operations 匯入成具名的設定快照，再載入並 Commit
手動：set 指令在 CLI 設定模式貼上指令後 Commit；建議一次貼 30 至 40 行以內

踩坑：完整 XML 是「取代」，不是「合併」

載入完整 XML 設定檔會取代現有設定，而不是與現有設定合併。在已經有設定的設備上直接載入，原本的介面、政策可能就沒了。要合併，得用 load config partial 並指定要的 xpath。載入前先備份目前設定（第 4 章），並先在測試設備或新設備上演練。Excel 範本也只應編輯 values 工作表，改其他工作表會破壞公式。

版本差異

  • 教材（簡報 2017～2020 年）把 IronSkillet 稱為「GitHub repository 中的 Day 1 設定範本」。這個專案目前以 Skillet Player（panHandler）與 SLI 為主要載入工具。
  • IronSkillet 的範本依 PAN-OS 版本分支維護。截至 2026 年 10 月查證時，公開分支最新為 panos_v11.0（2023 年 2 月更新），沒有 11.1 以後或 12.x 的分支。用在 12.x 設備前，請視為參考範例而不是可直接載入的設定，並對照現行原廠最佳實務逐項檢查；使用前也請到 GitHub 專案再確認一次分支清單。
  • 範本是起點而非終點：它依 Palo Alto Networks 的最佳實務編寫，但實際環境仍要評估（例如設備型號的設定檔數量限制、既有的政策）。
